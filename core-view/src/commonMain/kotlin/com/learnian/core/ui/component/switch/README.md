# ClaySwitch

کلید تاگل خمیری ۳بعدی با شیار فرورفته (`clayInsetGrooved`) و کلید لغزنده شناور (`clay-thumb`) با انیمیشن روان تغییر وضعیت.

## Features
- **ترک فرورفته (`clayInsetGrooved`)**: فرورفتگی عمیق و هایلایت داخلی شیار کلید.
- **تامب برجسته ۳بعدی**: لغزنده گرد و برجسته خمیری متحرک با انیمیشن تغییر رنگ فعال/غیرفعال.

## Code Example

```kotlin
ClaySwitch(
    checked = isEnabled,
    onCheckedChange = { isEnabled = it }
)
```
