# ClayProgressBar

Claymorphism progress indicator implementing **Progress Track Inset Grooved** track with raised action clay indicator.

## Features
- **Sunken Track**: Smooth dug-in background track.
- **Floating Progress Clay**: Smoothly animated progress indicator.
- **Customizable**: Adjustable height, corner radius (`Pill` or custom), and colors.

## Code Example

```kotlin
ClayProgressBar(
    progress = 0.75f,
    progressColor = ClayTheme.colors.secondary // Mint green progress
)
```
