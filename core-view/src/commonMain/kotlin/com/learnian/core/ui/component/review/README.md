# ClayReviewBannerCard Component

کارت بنر و دکمه قهرمان تعاملی مرور هوشمند مبتنی بر FSRS v5.

## مشخصات طراحی
- **سطح**: Surface 1 Resting Float با گوشه‌های `AppCorners.XL` و بک‌گراند نرم با هایلایت خمیری.
- **تگ الگوریتم**: چیپ قرصی خمیری با نقطه وضعیت بنفش.
- **تصویرسازی**: تصویر سه‌بعدی زاویه‌دار دفترچه/فلش‌کارت در سمت چپ.
- **دکمه اکشن برجسته**: دکمه اکشن ۳بعدی خمیری بنفش با کپسول زمان تخمینی، متن شروع و آیکون موشک بوستر.

## نحوه استفاده
```kotlin
ClayReviewBannerCard(
    tagText = "الگوریتم تکرار هوشمند FSRS v5",
    title = "مرور موشک‌وار واژگان روزانه",
    description = "یادآوری کلمات درست قبل از لحظه فراموشی مغز با ضریب پایداری پویا",
    timeEstimate = "۷ دقیقه",
    actionText = "شروع مرور هوشمند FSRS",
    onActionClick = { /* Handle review action */ },
)
```
